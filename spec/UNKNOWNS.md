# UNKNOWNS — Ledger of Unknowns

> Every uncertainty goes here (constitution §2). An UNKNOWN is a **blocker**, not a gap to fill
> by assumption. No gate is crossed with open UNKNOWNS that affect that phase's result.
>
> **Columns added for this project:** *Options* (★ = recommended) and *Decider*.
>
> **Decider = owner:** only Chris answers. Status becomes `resolved (owner: <message link>)`.
> The owner may answer "approve all recommendations"; that one message link is then the answer ID
> for every *owner* row it covers, each resolved to its ★ option.
>
> **Decider = delegated** (single source of the delegation rule; valid only if UNK-005 resolves to ★):
> an Architect thread decides from committed, reproducible evidence named in the row's *Evidence rule*,
> a Reviewer thread that did not write it signs it, and the status becomes
> `resolved (delegated: <review comment link>; authority: UNK-005 <owner message link>)`.
> If UNK-005 is rejected, delegated rows escalate to the owner like the rest.
